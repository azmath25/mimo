API access & endpoints

Turn a published Mimo workflow into a stable, versioned API that your quiz website or another app can call using a project key.

Manage published workflows ↗
Execution service required. Your current Cloud Run service has MIMO_API_ROLE=studio. Its /v1/workflows/{id}/runs endpoint is intentionally unavailable. To use external workflow APIs, deploy a separate Cloud Run service with MIMO_API_ROLE=execution, then enter that HTTPS URL in the endpoint generator below. Until that exists, generated addresses are templates—not live APIs.

1. Create an API project

Every integration gets its own project ID and randomly generated access key. The key is displayed only once.

Copy this key now. It cannot be retrieved again.
Store this only in the other application's server-side secrets. Never embed it in a public JavaScript frontend.




2. Grant a workflow
Choose an API project, select a published version and explicitly grant permission to run it.
