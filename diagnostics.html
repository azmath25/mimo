What is actually verified?

Service health checks verify database and storage connectivity, not successful model calls. Model registration status indicates whether a credential reference is configured, not whether the provider currently works. Use the model-specific Test action for a real, potentially billable provider call.

TikZ availability requires a deployed private TeX Live worker. Use TikZ Lab to verify an actual PDF/PNG compile. Background execution requires configured Cloud Tasks and worker service, and is not implied by an accessible Studio API.
