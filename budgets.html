Create or update a spending policy

Saving the same scope, ID and UTC period updates that policy. Lifetime limits never reset. Warn/monitor modes report cost without blocking. Hard/approval modes reject missing or unverified $0 prices. Approval is granted for one run only and never overrides a separate hard policy.

Price integrity · Is a model truly free?

Mimo cannot treat a manually entered $0 as verified-free. Inspect registered models and correct the source and prices in AI models before running protected workflows.

Expense alerts

A soft threshold records an alert when a reserved call crosses it. Alerts here are displayed on request; no email or push notification is installed.

Approve one expensive run

For a policy in Approval mode, first inspect the failed run and the provider cost estimate. An approval adds a bounded amount only to that run and expires automatically. Approval itself makes no provider call.

After approval, resume the paused/failed run explicitly from Runs & reviews; it is not executed automatically.

External API project concurrency

Limit simultaneous active runs from a project. Combined with a project daily/monthly cost policy, this prevents runaway API clients. A cap does not replace provider RPM limits.
