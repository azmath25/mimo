Security / External actions

Connectors & approvals

Install trusted adapters, grant operations to external projects, and approve exact side-effecting requests. Tokens remain in backend Secret Manager; workflow prompts never contain credentials.

Explicit approval is required for writes. A project grant alone never allows a GitHub issue to be created. Before approving, review the exact request and verify its project and destination repository. A timed-out action may already have succeeded remotely; uncertain actions are not retried automatically.
